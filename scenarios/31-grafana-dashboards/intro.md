## Grafana Dashboards

Grafana and a lean Prometheus are already installed, with the Prometheus datasource pre-provisioned. A dashboard screenshot can't be graded by a script -- what can be graded is whether the panel you build actually carries live data, which is exactly what this scenario proves through Grafana's own HTTP API.

**You will:**
1. Confirm Grafana is up and its Prometheus datasource is wired correctly
2. Build a dashboard through the API and prove its panel query returns real, current metric values

**Target time:** 45 minutes
