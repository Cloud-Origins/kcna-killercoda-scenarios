## kubectl Tooling & Contexts

Two namespaces, `dev` and `staging`, each with a running `worker` pod, are already there. No building -- this scenario is about working faster with the tool you already have: context defaults, structured output, and the built-in schema reference.

**You will:**
1. Set your context's default namespace and pull one field out with `-o jsonpath`
2. Use `kubectl explain` to answer a schema question without touching the docs site

**Target time:** 30 minutes
